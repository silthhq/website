# Internationalization

```yaml
# config/locales/fr.yml
fr:
  posts:
    created: "Article « %{title} » publié"
    count:
      zero: "Aucun article"
      one: "%{count} article"
      other: "%{count} articles"
```

```erb
<%= t("posts.created", title: post.title) %>
<%= t("posts.count", count: posts.total) %>
<%= l(post.created_at, "long") %>      <!-- 24 novembre 2026 à 10:00 -->
```

```yaml
# config/i18n.yml
default_locale: en
available_locales: [en, fr]
fallbacks: { fr-CA: fr }
```

The locale is resolved per request from `?locale=` (persisted in a cookie), a `:locale` route parameter, then `Accept-Language`. Plural rules follow CLDR for English, French, Slavic languages, Arabic and CJK. Validation messages and date names are translated (English and French built in).
